# Custom Object Detection and Facial Recognition

## 📌 Project Overview
This project focuses on building a custom **Object Detection and Recognition** pipeline capable of detecting and identifying a specific target person across varying environments, lighting conditions, and camera angles. 

The project covers the end-to-end computer vision workflow: custom dataset collection, data organization, bounding-box annotation, model training, and performance evaluation.
